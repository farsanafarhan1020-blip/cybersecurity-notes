# 💻 Learn Computer Fundamentals

> "Every cybersecurity professional should understand how a computer works before learning how to secure it."

---

# 🧩 What is a Computer?

A **computer** is an electronic device that accepts data, processes it according to instructions, stores it, and produces useful output.

### 🖥️ Basic Workflow

```text
Input → Processing → Storage → Output
```

**Example:**

⌨️ Keyboard → 🧠 CPU → 💾 SSD → 🖥️ Monitor

---

# 🧠 CPU (Central Processing Unit)

## 📖 Definition

The **CPU** is the **brain of the computer**. It executes instructions, performs calculations, and controls all computer operations.

### 🎯 Responsibilities

- Execute programs
- Perform calculations
- Process data
- Control other hardware components

### 💡 Example

When you open Chrome or play a game, the CPU processes all the required instructions.

---

# 🧠 Memory (RAM)

## 📖 Definition

**RAM (Random Access Memory)** is the computer's **temporary memory** used to store data and programs that are currently running.

### 🎯 Characteristics

- Very fast
- Temporary (Volatile)
- Data is lost when the computer is turned off

### 💡 Example

When you open multiple browser tabs, they are stored in RAM for quick access.

---

# 💾 Storage

## 📖 Definition

**Storage** is where data is stored **permanently**, even after the computer is turned off.

### Common Types

- SSD (Solid State Drive)
- HDD (Hard Disk Drive)
- USB Flash Drive
- Memory Card

### 🎯 Purpose

- Store Operating System
- Store Applications
- Store Files
- Store Photos & Videos

### 💡 Example

Your documents, games, and movies are stored on the SSD or HDD.

---

# ⚙️ Hardware

## 📖 Definition

**Hardware** refers to the **physical parts** of a computer that you can see and touch.

### Examples

- CPU
- RAM
- Motherboard
- SSD/HDD
- Keyboard
- Mouse
- Monitor
- Printer

---

# 💻 Software

## 📖 Definition

**Software** is a collection of programs and instructions that tell the hardware what to do.

### Types of Software

### 🖥️ System Software

Controls and manages the computer.

Examples:
- Windows
- Linux
- macOS

### 📱 Application Software

Helps users perform tasks.

Examples:
- Chrome
- Microsoft Word
- VLC Media Player
- Photoshop

---

# 🔄 Hardware vs Software

| Hardware | Software |
|----------|----------|
| Physical components | Programs & applications |
| Can be touched | Cannot be touched |
| CPU, RAM, SSD | Windows, Chrome, MS Word |

---

# 🔢 Binary Data

## 📖 Definition

Computers understand only **Binary**, a language made up of **0s and 1s**.

- **0** = OFF
- **1** = ON

Every letter, number, image, video, and program is ultimately stored as binary data.

### 💡 Example

The letter **A** in ASCII is stored as:

```text
01000001
```

---

# 💾 How Computers Store Information

Computers store information using **bits** and **bytes**.

### 📌 Units of Data

| Unit | Meaning |
|------|---------|
| Bit | Smallest unit (0 or 1) |
| Byte | 8 Bits |
| KB | 1024 Bytes |
| MB | 1024 KB |
| GB | 1024 MB |
| TB | 1024 GB |

### Example

The word:

```text
HI
```

is stored as binary values inside the computer.

The computer doesn't understand the letters **H** or **I**—it only understands their binary representation.

# 🌍 Real-World Example

Imagine you're writing a document.

⌨️ **Keyboard** → Input

🧠 **CPU** → Processes your typing

🧠 **RAM** → Temporarily stores the open document

💾 **SSD** → Saves the document permanently

🖥️ **Monitor** → Displays the document

Without any one of these components, the computer cannot perform the task properly.

---

# 💭 Easy Way to Remember

Imagine a **restaurant**.

👨‍🍳 **CPU** → Chef (Processes orders)

📝 **RAM** → Kitchen Counter (Temporary workspace)

🥫 **Storage** → Pantry (Stores ingredients permanently)

🍽️ **Hardware** → Kitchen equipment

📖 **Software** → Recipe book telling the chef what to cook
